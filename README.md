# Python Calculator 

An interactive command-line calculator built with Python as a personal learning project. It supports basic mathematical operations and includes input validation and error handling.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Exponentiation
- Remainder (modulo)
- Square root
- Interactive menu with an exit option
- Input validation using exception handling
- Error handling for division and remainder by zero
- Negative number validation for square roots

## Technologies

- **Python 3**
- **`math` module** for square root calculations

## Concepts Practiced

This project helped me practice and improve my understanding of:

- Functions (`def`)

- Exception handling (`try`, `except`)
- User input and type conversion (`input()`, `float()`)
- Returning and unpacking multiple values (`return`)
- Code reusability

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone this repository or download the source code.
3. Open a terminal in the project directory.
4. Run the following command:

   ```bash
   python advanced.calculator.py
   ```

5. Select an operation from the menu and follow the instructions.
